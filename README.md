# Focus & Doa

Muslim Daily Focus & Productivity Companion.

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Database & Auth**: Supabase
- **PWA**: Progressive Web App ready
- **Deployment**: Vercel

## Setup Lokal

1. Clone repository.
2. Jalankan `npm install`.
3. Buat file `.env.local` berdasarkan `.env.example`.
4. Jalankan server lokal: `npm run dev`.

## Struktur Folder

- `src/app`: Halaman-halaman utama (App Router)
- `src/components`: UI components reusable
- `src/lib`: Integrasi API, Supabase client
- `src/utils`: Helper logic (Kalender Jawa, Weton, Choghadiya)
- `src/data`: Data static (Doa, dll)
